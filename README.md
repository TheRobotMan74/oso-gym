# Oso Gym

App instalable (PWA) para llevar la rutina, registrar series y pesos, ver el progreso y contar calorías y proteína.

**Abrir:** https://therobotman74.github.io/oso-gym/

## Instalar
- **iPhone (Safari):** botón Compartir → *Agregar a pantalla de inicio*.
- **Android (Chrome):** menú ⋮ → *Instalar app*.
- **Compu (Chrome o Edge):** ícono de instalar en la barra de direcciones.

## Datos
Todo se guarda solo en el navegador de cada equipo; nada se sube a ningún servidor. Para pasar los datos de un equipo a otro: *Más → Respaldo → Descargar* y en el otro equipo *Importar desde archivo*.

El escáner de códigos de barras consulta [Open Food Facts](https://world.openfoodfacts.org) cuando no conoce un producto. Los valores de los alimentos incluidos son aproximados.
